## 前言

2025年的最后一天，在黄山的山顶上落下尾声。云海如帷幕般合拢谢礼，也该好好总结一下，与2025年正式告别。

回望2025年，一大半时间是在迷惘踌躇。迷惘的是AI带来的职业冲击，踌躇的是不知道未来该如何发展。AI应用越来越普遍，我也开发了一些AI Agent。就目前情况来说，AI的能力是有限的。让AI从总体去设计是可行的，针对某个问题的细节提供答案也是可以的，但是从总体落实到方方面面，让AI来做总是一团乱麻。生成的代码既繁琐复杂，缺乏整洁性，又云里雾里，看得我晕头转向。不过这也已经很强了，强到我开始怀疑我这些年所学所做的意义何在。兴许明年AI的能力再进化进化，我这般水平的开发人员就是可有可无的了，到时候我又该何去何从呢？

还是先回顾下年初计划吧，看看过去的一年都做了什么。

## 技能

年初计划学习或复习以下技能：

- 前端开发 -> 只有在前端开发都离职的时候认真学了几天，如今也只会简单的页面调试和接口调用。
- 设计模式 -> 23种设计模式是学完了，但实际应用到的只有几种，而且也没必要上设计模式。与其说是设计模式，我个人认为重点在于设计思想。
- 《流畅的Python》 -> 看完了，也应用到了，这本书的确不错。
- kube operator -> 学了一点点，没学会。
- Pytorch图像识别 -> 一点没学。
- Postgres -> 整理出来了一个够我自己用的技能图谱
- 经典算法 -> 复习了一遍
- Go语言 -> 复习加整理技能图谱
- 厨艺 -> 发现自己只喜欢炒点或蒸点蔬菜，少盐少油。
- 盆栽 -> 没养。
- 绘画 -> 一点没学。

另外学了点其它的

- 英语 -> 年初的时候开始跟着多邻国复习英语
- AI Agent -> 学会了MCP和LangGraph

年初计划了很多，但实际上手就没有什么动力了，大多搁浅。只要一想到AI都能做好，就更没动力了。
